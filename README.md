# ColorPencil ERP (색연필 제조 ERP / Hệ thống ERP bút chì màu)

## 저장소 · 받기 / Kho mã nguồn · Tải về
- 소스: GitHub `bosungerppro-source/Bosung-ERP` (브랜치 `main`). 차수별 결정 · 작업 기록은 `docs/`.
- 설치 파일 · 데모: 저장소의 **Releases**. 새 Release 는 **Actions → "Release — 설치 파일" → Run workflow** 에서 버전(예: `1.10.0`)을 넣으면 GitHub 가 설치 파일과 데모를 빌드해 태그와 함께 만듭니다. **1.10.0 부터는 이 버튼이 곧 모든 PC 배포입니다** — 설치한 ERP 가 Release 를 보고 다음에 켤 때 새 버전을 설치합니다 (`.github/workflows/release.yml`, 설명은 `docs/releases/v<버전>.md`).

## 사용 방법
1. 설치 후 실행 → **ECOUNT 자료(2026-10-16)** 가 들어 있습니다: 품목 2,265 · 창고 11 · ERP CODE 사전 · 기초재고(창고 314 / 공장 962행). 예전 샘플(수주·생산일보·BOM 등)은 **"예시"** 로 표시되며, **설정 → 예시 데이터 한 번에 삭제**로 예시 행만 지울 수 있습니다 (새로 올리거나 입력한 행은 남음).
   - 재고 = 기초재고 + 그 뒤의 수불(입고·출고·이동·조정) + 생산일보 자동 반영(입고 + BOM 현장 부품 차감 — 원부자재는 차감하지 않음). 공정 중 재고는 현장 실사(TỒN KHO)를 올리면 그 수량 · 기준일에서 시작합니다. 화면은 왼쪽 메뉴 **품목** · **현장 재고** · **원부자재 재고** (12차부터 셋으로 나뉨).
   - 매일: 생산일보와 수불(양식 또는 KHO NVL 입출고장)을 **엑셀 업로드**에 올리거나, 급한 건은 **원부자재 재고 → 수불 입력** (현장 재고 조정은 **현장 재고 → 수불 입력**).
   - 원부자재는 **창고 입출고장(BẢNG KÊ NHẬP XUẤT)** 을 엑셀 업로드에 올리면 품목 · 1월 1일 기초재고 · 입고 · 출고가 들어가고, 마지막 날 재고가 파일의 재고와 같아집니다. ECOUNT 재고현황을 같이 올리면 없는 품목만 보완합니다 (마이너스 0). 창고 파일에 있는 반제품(외주에서 받아 창고에 있는 것)은 그 반제품의 **창고** 재고로 들어가고 (1.10.1, 현장 재고 메뉴의 창고 칸), 현장으로 분출하면 수불 입력의 이동(창고 → 공장)으로 옮깁니다. 창고 파일에 완제품 번호로 적힌 포장 카톤은 원부자재로 두고, 같은 번호의 포장 일보 생산량은 카톤 재고에 더하지 않습니다 (1.10.2).
   - **해외 주문 품목 (1.11.0)**: 자재구매 파일(`Category · Item Code · Safety stock …` 표)을 엑셀 업로드에 올리면 그 품목의 안전재고가 들어가고, **원부자재 재고 → "해외 주문 품목만" 버튼 (해외 주문 탭)** 에서 파일과 같은 칸 순서의 표로 따로 봅니다. 주문일 칸에 수량을 넣어 주문하고, 리드타임(주문 → 입고 일수)을 넣으면 도착 예정 · 주문 필요 · 권장 주문량을 계산합니다. 자재구매 파일의 재고(H열 Inventory)가 맞는 재고라서, 올리면 파일 날짜에 조정이 들어가 ERP 재고가 파일 값과 같아집니다 (1.11.1). 같은 코드가 다른 구분으로 또 있으면 (예: BIC 업체용으로 창고를 나눈 원료) 따로 관리하는 줄로 보입니다 (1.11.2). 주문할 때는 **[주문 파일 만들기]** 가 안전재고 자릿수 단위(백 단위 100, 천 단위 1,000 …)로 올린 권장 주문량을 넣고, 자재구매 파일과 같은 서식의 엑셀을 만듭니다 (1.11.3).
   - ECOUNT 는 2026-11 부터 쓰지 않습니다. ECOUNT 파일은 처음 자료(품목 · 창고 · ERP CODE 설명 · 기초재고)를 옮길 때만 올립니다 (ECOUNT 비교 기능은 12차에서 없앰).
2. **종합 현황 꾸미기 (위젯)**: `✎ 화면 편집` → 위젯을 끌어서(또는 ◀ ▶) 순서 바꾸기, `1 2 3 4` 로 가로 크기, ⚙ 로 공정 고르기, ✕ 로 빼기, `+ 위젯 추가` 로 숫자·표·차트 추가 (재고 칸의 **현장 재고 (공정별 현재 재고)** — 현장 재고 위 표와 같은 표, 1.12.2. 이 위젯의 ⚙ 에서 **품목군을 여러 개 고르면 고른 것만** 보입니다, 1.13.6) → `편집 완료`. `기본 배치로` 를 누르면 기본 배치(1.12.5: 이번 달 포장 누계 · 신규 수주 · 수주량 · 조립 재고 → 월별 수주량 · 공정별 실적 · 월별 조립 생산량)로 돌아갑니다. **이번 달 포장 누계는 pcs** 입니다 (1.12.3, 포장 일보의 pcs 칸 합 — pcs 가 빈 줄은 카드에 알림). 이번 달 포장 누계 · 신규 수주 · 수주량 카드 아래에는 **지난달 값**이 같이 보입니다 (1.12.4). 배치는 ERP 에 저장되어 같은 ERP 에 접속하는 모든 PC 가 같이 봅니다.
   - 월별 수주량은 **Checking(납기) 일 기준 pcs**, 일별 생산량 표는 **한 달 · 품목군별 조립**이 기본입니다. **월별 조립 생산량**(품목군 × 1~12월)은 일별 바로 아래에 있고, 생산 관리에도 **일별 조립 생산량 · 월별 조립 생산량** 탭이 있습니다 (1.10.1). 생산 관리의 두 표는 **가로 = 날짜 (일별 1일 ~, 월별 1 ~ 12월), 세로 = 품목군** 입니다 (1.13.7, 종합 현황 위젯과 같은 모양 · 엑셀도 같음). 표 위의 **품목군 체크로 여러 개를 고르면 고른 것만** 보입니다 (1.13.8 — 두 탭이 같이 쓰고 저장됨). 종합 현황의 일별 · 월별 조립 생산량 위젯도 ⚙ 에서 품목군을 여러 개 고릅니다. 품목군 칩을 눌러 보고 싶은 품목군만 고르면 종합 현황과 수주 관리에 같이 적용됩니다.
3. **현장 재고 / 원부자재 재고**: 왼쪽 메뉴 **원부자재 재고**(원재료 RM · 부자재 SM · 소모품 CM)와 **현장 재고**(심 → 배럴 → … → 조립 → 포장)가 따로 있고, 수불 입력 · 수불 내역도 메뉴마다 그쪽 품목만 다룹니다. 생산일보를 올리면 생산량이 현장 재고로 들어가고(`생산 입고 +`), 조립 수량만큼 현장 부품이 빠집니다(`소모 −`). 원부자재는 생산 반영으로 차감하지 않습니다. 포장 일보에는 박스 코드만 적히므로, 박스 BOM 의 세트(SG · 마니라)는 빼지 않고 세트 안의 조립품을 포장 set 만큼 뺍니다 — 포장한 만큼 조립 재고가 줄어듦 (1.13.10, 세트는 1.13.9 부터 빼지 않음 · 일보가 세트를 직접 만든 경우만 예전처럼). 현장 재고 위는 **피벗 표**입니다 (1.12.0 · 1.12.1). 기본은 조립 재고 · 품목군(Mini · Dial · Pencil · Click pencil …) | **현재 재고**이고, 표마다 [설정]에서 공정 · 품목군 · 행 · 열 · 범위를 고르며 [+ 표 추가]로 다른 공정 표를 더 만듭니다 (색깔 구분 없이 합계 — 칸을 누르면 아래 표가 그 품목으로). 표 오른쪽 **원재료 환산** 은 현장 재고를 BOM 으로 원료까지 푼 원재료별 kg (공정별 칸 · 엑셀, 1.13.9 — 종합 현황 "+ 위젯 추가" 에도 있음). 제품 · BOM · 배합 → 소요량 계산의 **진행 중 수주에서 가져오기** 는 [전체 선택] · 범위 (진행 전만 / 진행 중 포함) · 줄마다 진행 상태 · 진행률이 있습니다 (1.13.9). 생산 관리 → 일보 조회에는 포장 일보의 **PO 번호**와 **수주 보기 →** 가 있습니다.
   - 이름이 확인되지 않은 코드(제품군 GRA · MIX, 세부 NEON · PAS … 등)는 이름 대신 코드만 보입니다. 같은 이름을 쓰는 단계(부품 = WIP06·x6 · WIP15·25·35 · WIP11 · WIP21·31… · WIP55)는 목록 · 필터에 "부품 · WIP11" 처럼 코드가 같이 보입니다. **품목 → 코드 사전**에 이름을 넣으면 화면 전체에 바로 나옵니다.
   - 처음 한 번: `제품·BOM → 조립 BOM 자동 구성` → `확실한 부품만 모두 적용` (노랑 행은 드롭다운으로 부품을 골라 적용). 그다음 `현장 재고 → 생산 반영` 탭에서 "해결할 항목"을 0 으로 (일보 코드 ↔ 품목코드 연결, BOM 없는 생산품).
4. 언어: 왼쪽 아래 **한국어 / Tiếng Việt** 버튼. **설정 → 붙여넣기 숫자 형식**: 엑셀에서 붙여넣은 수량이 1000배로 틀리면 바꾸세요 (자동 = 이 PC 형식, 베트남어 PC 는 35.000 = 3만 5천).
   - 수주 관리: Condition 칸이 취소(Cancle) · 보류(Di hold)인 줄은 진행 중 · 납기 경과에서 빠지고 **취소 · 보류** 탭에 모입니다.
   - 수주 관리: 끝난 PO 는 수주 목록의 **완료** 버튼으로 닫습니다 (포장 실적과 상관없이 완료, 확인 창). 잘못 눌렀으면 **완료** 탭에서 **완료 취소**.
   - 수주 관리: 수주 목록 (PO별 보기) 칸은 PO 번호 · 거래처 · 품번 · **품목군** · 세트 · 납기입니다 (1.13.12, 품번 수 대신 품목군 — 여러 개면 "Mini · Pencil", 검색에도 걸림). 납기는 늦은 날짜부터 보입니다 — 수주 목록 두 보기, 종합 현황 "납기 임박 수주", 휴대폰, MRP "진행 중 수주에서 가져오기", 품목 상세의 진행 중 수주 (납기 없는 줄은 맨 뒤).
   - 수주 등록: 고객 수주서 엑셀 (시트마다 PO 하나 — 수입자 · 주문일자 · P.O. # · Item No., .xls 도 됨) 을 **엑셀 · 구글 연동 → 자료 올리기** 에 그대로 올리면 시트마다 수주가 됩니다 (1.13.11). 이미 있는 PO 는 PO 번호 + 품번으로 세트 · 카톤 · pcs · 납기만 갱신하고, 올리기 전에 추가 · 갱신 · 바뀌는 값을 보여 줍니다. Item No. 가 없거나 벌크인 품목은 읽지 않고 알려 줍니다.
5. **엑셀 업로드**: `엑셀·구글 연동 → 엑셀 업로드`에 파일을 여러 개 한 번에 끌어다 놓기 → 인식 결과·미리보기 확인(반영 방식·범위·날짜 수정) → **선택 항목 모두 반영** (직후 **되돌리기** 가능).

   - 생산일자를 읽지 못한 일보는 날짜 칸이 비어 있습니다 — 날짜를 넣으면 반영할 수 있습니다. 파일명 날짜와 다르면 노란 경고와 "파일명 날짜 적용" 버튼이 나옵니다.
   - 현장 일보의 날짜 칸은 `docs/GUIDE_EXCEL_DATES.md` 대로 넣어 주세요 (가장 안전한 형식 `2026-10-08`, 엑셀 입력 제한 거는 법 포함).
   - 날짜를 읽지 못한 수불 줄은 "날짜를 읽지 못함"으로 표시되고 반영되지 않습니다 (17/10/2026 같은 일/월/년 글자 날짜는 읽습니다).

8. **여러 PC 공유(LAN)**: 앱 메뉴에서 LAN 모드를 켜면 같은 네트워크의 브라우저로 접속할 수 있습니다 (설정 화면에 주소 표시).
   - **사내망 PIN (1.4.0)**: 다른 PC 의 브라우저는 처음 한 번 PIN 을 넣어야 들어옵니다 (7일 기억). ERP 가 실행 중인 PC 의 **설정 → 사내망 PIN 정하기**에서 숫자 4~12자리로 정하세요. **PIN 을 정하지 않으면 다른 PC 는 들어오지 못합니다.** PIN 을 바꾸면 다른 PC 는 새 PIN 을 다시 넣습니다. 5번 틀리면 잠시 잠깁니다.
   - **구글 비밀 키 (1.13.3)**: 다른 PC 의 브라우저에는 구글 비밀 키 (TOKEN) 를 보내지 않고, 그 브라우저에서는 Apps Script 주소 · 키를 바꿀 수 없습니다 (ERP 가 실행 중인 PC 에서만). 그 브라우저의 구글 시트 올리기 · 가져오기는 ERP 가 키를 넣어 그대로 됩니다.
   - **여러 PC 동시 사용 (1.4.0)**: 여러 PC 가 같은 표를 동시에 고쳐도 서로 지우지 않고 행 단위로 합쳐 저장합니다. 같은 행을 두 PC 가 동시에 고쳤으면 나중에 저장한 PC 의 내용이 남고 알림이 나옵니다. 다른 PC 의 변경은 20초마다(창으로 돌아올 때도) 불러오고, 입력 중이 아니면 화면을 다시 그립니다 (입력 중이면 왼쪽 아래 "다른 PC 변경 있음 · 새로 고침").
   - 저장에 실패하면(네트워크 끊김 등) 입력한 내용을 버리지 않고 자동으로 다시 저장합니다 (왼쪽 아래 "저장 오류" → "저장됨").
9. **자동 업데이트 (1.10.0)**: 설치한 ERP 가 켤 때와 4시간마다 GitHub 에 새 버전이 있는지 보고, 있으면 설치 파일을 받아 두었다가(SHA-256 확인) **다음에 켤 때** 설치합니다 — 진행 막대가 잠깐 보이고 새 버전으로 켜집니다. 바로 하려면 화면 위 알림이나 **설정 → 프로그램 업데이트**의 **[지금 업데이트]**. 일하는 중에는 저절로 다시 시작하지 않습니다.
   - 설치 전에 데이터 폴더를 `%APPDATA%\ColorPencil ERP\update_backup` 에 복사합니다 (최근 5번). 끄기 · 지금 확인: 설정 카드 또는 프로그램 메뉴 `ERP → 업데이트 확인… · 자동 업데이트`.
   - 1.9.0 이하가 설치된 PC 는 1.10.0 설치 파일을 **한 번** 직접 덮어 설치하세요. 인터넷(github.com)이 안 되는 PC 는 지금 버전 그대로 동작합니다.
10. **휴대폰으로 보기 (1.10.0)**: **설정 → 휴대폰으로 보기**.

   - **공장 밖에서**: Code.gs 4판 이상 (1.13.0 부터 5판 · 1.13.2 부터 6판 · 1.13.3 부터 7판) 을 배포하고 엑셀 · 구글 연동의 "여러 PC 자료 공유" 카드에서 연결한 뒤 (아래 11) 카드에서 비밀번호(6~32자)를 정하면, ERP 가 15분마다 종합 현황 · 생산 관리 요약을 구글로 보냅니다. 휴대폰은 카드의 QR(웹 앱 주소)을 열고 비밀번호를 넣습니다 (10번 틀리면 10분 잠금, 비밀번호는 구글 쪽에 해시로만). 7판은 "이 휴대폰에서 기억" 을 하면 비밀번호 대신 그 휴대폰의 열쇠를 기억해, 잠긴 동안에도 기억해 둔 휴대폰은 바로 보입니다 (비밀번호를 바꾸면 다시 넣어야 함).
11. **여러 PC 자료 공유 — 구글 드라이브 (1.13.0)**: 사장님 PC 와 직원 PC (몇 대든) 에 따로 설치한 ERP 가 같은 자료를 씁니다. 직원들이 입력 · 엑셀 업로드한 자료가 구글 드라이브 한 곳에 모여 모든 PC 에 업데이트됩니다. `엑셀 · 구글 연동 → 구글 시트 · 드라이브` 맨 위 카드.

   - 종합 현황 배치 · AI 비서 · 붙여넣기 숫자 형식 · 휴대폰 보기 켜짐은 PC 마다 따로입니다. 자료는 구글 드라이브 "ColorPencil ERP Data" 폴더.
   - 휴대폰: 같은 웹 앱 주소 — 설정 → 휴대폰으로 보기에서 비밀번호를 정하세요 (위 10).
   - **구글 시트에서 표로 보기 (1.13.2, Code.gs 6판)**: Apps Script 를 만든 그 구글 시트에 표마다 탭 (ERP 화면과 같은 이름 · 머리글) 과 맨 앞 "ERP 자료 안내" 탭이 생기고, 어느 PC 가 저장하든 30초 안팎에 저절로 바뀝니다 (큰 표는 1분쯤). 시트에서는 보기만 — 고치는 것은 ERP 에서 (시트에서 고친 것은 다음 갱신 때 덮어씀). 카드의 시트 링크 · [구글 시트 다시 쓰기].

## 나만의 AI 비서 (Trợ lý sản xuất của tôi)
화면 우측 하단 **✦ 버튼**(기본 이름 "AI 비서")을 누르면 열립니다. 비서는 ERP 데이터를 **읽기만** 하며(수정·삭제 불가), 숫자는 종합 현황 화면과 같은 기준으로 계산합니다.

**두 가지 모드**
| 모드 | 조건 | 특징 |
|---|---|---|
| **내장 모드** (기본) | 아무 설정 없이 바로 사용 | API 키·인터넷 불필요, 데이터가 PC 밖으로 나가지 않음. AI 가 아니라 **정해진 질문 유형**(한국어·베트남어·영어)을 이해합니다. 모르는 질문은 지어내지 않고 예시를 보여줍니다. |
| **AI 모드** | ⚙ → Anthropic API 키 입력 | 자유로운 대화. 질문에 필요한 조회 결과(수주·재고·생산 수치)가 Anthropic API 로 전송되고 사용 요금이 듭니다. 연결이 실패하면 자동으로 내장 모드로 답하고 이유를 알려줍니다. |

**이렇게 물어보세요** (베트남어는 성조 없이 써도 됩니다)
- `오늘 브리핑` · `Bản tin hôm nay` — 최근 생산, 납기 위험 PO, 안전재고 미달 자재를 한 번에
- `납기 위험 PO` · `오래된 지연 PO` · `PO sắp đến hạn`
- `5100361450` (PO 번호) · `5100361450 자재 소요량` · 품번(`52-0712-0-009`)
- `안전재고 미달 자재` · `HDPE 재고` · `R-001 재고` · `발주 필요한 자재`
- `어제 생산 요약` · `이번 주 포장 실적` · `조립 지난주 실적` · `Sản lượng hôm qua`
- `어제 불량률` · `설비 정지 시간` · `tỷ lệ lỗi tháng này`

답변은 **표 + 표 밑 코멘트(※)** 로 보입니다. 답변 아래의 버튼(예: "수주 관리 열기", "이 PO 열기", "MRP 화면에서 보기")으로 해당 화면으로 바로 이동하고, `⧉ 복사` 로 메신저에 붙여넣을 글자 버전을 복사합니다. 창 위쪽 `⤢` 버튼으로 창을 넓게 볼 수 있습니다.

**내 비서 만들기** — 창 위쪽 ⚙
- **비서 이름 · 나를 부르는 호칭** (예: "소미", "박 팀장님") — 버튼과 인사말에 표시
- **답변 스타일** 간단히 / 자세히, **우리 공장 지침** (용어·우선순위·답변 형식 — AI 모드에서 항상 따름. 다른 프로젝트에서 만든 비서 지침을 붙여넣어도 됨)
- **내 단축 질문** 최대 8개 — ★ 버튼으로 표시
- **AI 사용 안 함** — 내장 모드만 사용 (데이터가 외부로 나가지 않음)
- 설정은 ERP 설정에 저장되어 **백업에 포함**되고 "전체 삭제"를 해도 남습니다.

**API 키 보관**: 설치형은 `data/ai.json`(본인만 읽기)에만 저장하며 화면에는 끝 4자리만 보입니다. 키 · 모델 · **하루 AI 호출 한도**(기본 400, 0 = 제한 없음)는 ERP 가 실행 중인 PC 에서만 바꿀 수 있습니다(LAN 의 다른 PC 브라우저는 내 비서 설정만 저장). LAN 브라우저에서도 비서를 *사용*할 수 있으므로 한도로 요금을 관리하세요 — ⚙ 에 오늘 사용량(호출 · 토큰)이 보입니다. 데모(`ERP_Demo.html`)는 키를 그 창의 메모리에만 둡니다 (새로 고치면 다시 입력).

**AI 모드 동작 (1.4.0)**: 기본 모델 `claude-sonnet-5-5` (⚙ 에서 바꿀 수 있음). 프로그램을 다시 열어도 AI 모드가 유지됩니다. 대화가 길어지면 앞을 자르지 않고 요약으로 새 대화를 엽니다. AI 가 안전 정책으로 답하지 않으면(거절) 이유를 보여주고 내장 모드로 답합니다 — 거절되면 Anthropic 이 알맞은 다른 모델로 다시 답하게 하는 기능(fallbacks)이 켜져 있습니다. 혼잡(429/529)이면 잠시 기다렸다 한 번 더 시도합니다. ⚙ 의 **AI 연결 시험**은 모델 이름과 걸린 시간을 보여줍니다.

**알아둘 점**
- 납기 경과 PO 는 대시보드와 같이 *납기 후 60일 이내*만 셉니다. 60일을 넘긴 PO 는 "오래된 지연 PO"로 따로 안내합니다. (참고: 메뉴 배지는 30일, 수주 화면 KPI 는 90일 기준이라 화면마다 창이 다릅니다.)
- 안전재고는 설정한 품목만 판단하므로 "부족 없음"은 "설정된 품목 중 없음"입니다. 안전재고는 ECOUNT 품목등록 값을 쓰고, **원부자재 재고 → 발주 · 안전재고**에서 고칠 수 있습니다.
- 재고 답변에는 기초재고 기준일과 마지막 수불일이 함께 나옵니다.
- 자재 소요량(MRP)은 BOM 에 부품 코드·배합표가 없으면 "계산 불가"로 알려줍니다 ("부족 없음"이 아님).
- 시험: `npm i -D playwright` 후 `npm run test:assistant` (실제 Anthropic API 는 호출하지 않음).

## 1.14.1 — 해외 주문: 수주에 필요한 만큼 주문 · 주문 파일 칸 줄이기

- **권장 주문량 = 수주 관리의 진행 중 수주를 만들 양 (MRP) + 안전재고 − (재고 + 입고예정 + 입고 대기 주문)** — 원부자재 재고 → 해외 주문.
  - 수주에 쓰는 품목이 모자라면 모두 "주문 필요" 가 되고, [권장 주문량 넣기] · [주문 파일 만들기] 가 그 양을 주문일 칸에 넣습니다 (주문 단위로 올림).
  - 표에 **수주 필요 (MRP)** 칸이 생겼습니다 (상태 바로 앞). 칸에 마우스를 올리면 처음 모자라는 수주 · 필요한 날이 보입니다.
  - 위에서 수주 범위를 고릅니다: PO미정 포함 (기본) / 확정 PO 만 — 생산 계획과 같은 계산입니다.
  - 수주에 안 쓰는 품목은 예전처럼 안전재고 + 리드타임 동안 쓸 양 기준입니다.
- **만든 주문 파일에서 Safety stock · kg/month · ea/month · Max · Min · Average 칸을 뺐습니다.** 칸: Category · Item Code · Item Name · Item Name Kr · Unit · Inventory · 입고예정 · 주문일 · Total. 이 파일을 다시 올려도 자재구매 파일로 알아봅니다.

**받을 파일**
- `ColorPencil-ERP-Setup-1.14.1.exe` — Windows 설치 파일 (1.10.0 이상은 자동 업데이트)
- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모 (공유 기능은 설치형에서만)
- `latest.json` — 자동 업데이트가 보는 파일

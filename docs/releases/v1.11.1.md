## 1.11.1 — 해외 주문 품목의 재고를 자재구매 파일에 맞춤

- **자재구매 파일의 재고(H열 Inventory)가 맞는 재고**입니다. 자재구매 파일을 올리면 "재고를 파일 재고(Inventory)에 맞춤" 이 같이 반영되어, 품목마다 **파일 날짜에 조정**(용도 "자재구매 파일 재고 맞춤")이 들어가 ERP 재고가 파일 값과 같아집니다.
  - 같은 날짜의 파일을 다시 올리면 그 날의 조정만 다시 계산합니다 (두 번 더해지지 않음).
  - 파일의 재고 칸이 빈 품목은 그대로, 단위가 다른 품목(예: kg ↔ ROLL)은 개당 kg 로 바꿔 맞춥니다.
  - 원부자재 재고 → 수불 내역에서 출처 "자재구매 파일" 로 보입니다.
- 1.11.0 (해외 주문 탭 · 리드타임 · 주문) 과 1.10.x 의 내용도 들어 있습니다.

**받을 파일**
- `ColorPencil-ERP-Setup-1.11.1.exe` — Windows 설치 파일 (1.10.0 이상은 자동 업데이트)
- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모
- `latest.json` — 자동 업데이트가 보는 파일

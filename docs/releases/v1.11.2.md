## 1.11.2 — 같은 코드 · 다른 구분은 따로 관리하는 재고

- 자재구매 파일에 **같은 품목코드가 다른 구분으로 또 있으면** (예: R-015 · R-016 의 Pigment 와 BIC Pigment — BIC 업체 요청으로 창고를 나눠 따로 관리하는 원료) 해외 주문 탭에 **따로 관리하는 줄**로 보입니다.
  - 첫 줄은 ERP 품목 (창고 입출고장 재고), 다음 줄은 따로 관리하는 재고 — 재고는 자재구매 파일 값, 안전재고 · 리드타임 · 입고예정 · 주문 · 권장 주문량이 따로입니다. 코드 옆에 "따로 관리" 표시.
  - 같은 코드 · 같은 구분이 두 번이면 지금처럼 첫 줄만 씁니다.
- 1.11.1 (재고를 자재구매 파일에 맞춤) · 1.11.0 (해외 주문 탭) · 1.10.x 의 내용도 들어 있습니다.

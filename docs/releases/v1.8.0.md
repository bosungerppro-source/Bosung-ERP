## 13차 (v1.8.0) — 수주 강제 완료

- **수주 목록에 완료 버튼**: 수주 관리 → 수주 목록(PO별 보기)의 각 PO 끝에 **완료** 버튼이 생겼습니다. 누르면 확인 창이 뜨고, 포장 실적과 상관없이 그 PO 가 완료가 되어 진행 중 · 납기 경과 목록에서 빠집니다.
- **완료 취소**: 잘못 눌렀으면 **완료** 탭에서 그 PO 의 **완료 취소** 를 누르면 다시 진행 중이 됩니다. 상세 칸에도 "완료 처리 (날짜)" 와 같은 버튼이 있습니다.
- 취소 · 보류로 적힌 줄은 그대로 둡니다. 수주 엑셀을 다시 올려도(기본 방식) 완료 표시는 남습니다.
- 이 PC 의 수주: 납기(Checking)가 2025년 1월 ~ 2026년 9월인 수주를 모두 완료로 표시했습니다 (업로드 이력에 "po_close" 로 남음). 10월 납기부터 진행 중입니다.

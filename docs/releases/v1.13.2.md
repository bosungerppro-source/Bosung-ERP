## 1.13.2 — 구글 시트에서 표로 보기 (Apps Script 6판)

- 여러 PC 자료 공유에 쓰는 그 구글 시트에 **표마다 탭**이 생깁니다 — ERP 화면과 같은 이름 · 머리글 (수주 (PO) · 생산 일보 · 품목 마스터 …) 과 맨 앞 "ERP 자료 안내" 탭 (표 · 행 수 · 마지막 저장 · 보낸 PC).
- 어느 PC 가 저장하든 30초 안팎에 저절로 바뀝니다 (큰 표는 1분쯤). 시트에서는 보기만 하고, 고치는 것은 ERP 에서 하세요 (시트에서 고친 것은 다음 갱신 때 덮어씁니다).
- 엑셀 · 구글 연동 → 구글 시트 · 드라이브 → "여러 PC 자료 공유" 카드에 구글 시트 링크 · 상태 (최신 · 갱신 중 · 갱신 대기) · [구글 시트 다시 쓰기].
- 시트 쓰기는 자료 주고받기와 따로 돕니다 — 큰 표를 시트에 쓰는 동안에도 다른 PC 로 자료가 그대로 넘어갑니다. 한 표를 시트에 쓰지 못해도 (칸 한도 등) 다른 표와 자료 공유는 그대로입니다.
- 코드 · 날짜 (0414210300 · 2026-10-22) 는 글자 그대로, "=" 로 시작하는 입력은 수식이 되지 않게 씁니다.

**Apps Script 를 이미 배포했으면 (5판)**: [Apps Script 코드 복사] → Apps Script 편집기에 붙여넣기 → 저장 → 배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포 (주소는 그대로). 5판 그대로여도 자료 공유는 됩니다 (시트 표 보기만 없음).

## 1.13.14 — 생산 관리 · 위젯: 공정도 여러 개 골라 보기

- **생산 관리 → 일별 · 월별 생산량**: 공정을 하나만 고르던 드롭다운 대신, 품목군처럼 **체크로 여러 개**를 고릅니다 (예: 조립 + 종이 권취). '전체' 는 모든 공정이고, 처음은 조립입니다.
  - 공정 여러 개를 고르면 품목군 체크에는 그 공정들의 품목군이 모두 나오고, 숫자 카드 · 표 제목에는 고른 공정 이름이 나옵니다 (예: "월 생산량 (조립 · 종이 권취)").
  - 품목군 고르기는 공정 묶음마다 저장됩니다 (조립만 볼 때 고른 품목군은 예전 그대로).
  - 수량은 양품 pcs 입니다 (포장은 pcs 환산 — 예전 '공정: 전체' 와 같음).
- **종합 현황 '일별 · 월별 조립 생산량' 위젯**: ⚙ 의 공정도 체크로 여러 개 고릅니다. 예전에 고른 공정 하나는 그대로입니다.
- 1.13.13 (종이 권취 일보의 품목군 = Glass) 의 내용도 들어 있습니다. 구글 Apps Script 는 7판 그대로입니다.

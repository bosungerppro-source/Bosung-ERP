## 1.13.18 — 소요량 계산 (MRP): 수주 set 을 BOM 의 세트로 · 수주를 여러 번 가져와도 한 번만

- **수주 set 을 BOM 의 세트로 셉니다**: 수주 품번은 카톤 BOM (카톤 1 + 세트 ×12 → 세트 1 = 색연필 ×24 등) 입니다. 예전에는 소요량 계산이 수주 set 을 카톤 개수로 풀어서 세트 · 색연필 · 원료가 카톤당 세트 수만큼 (4 ~ 30배) 크게 나왔습니다. 이제 set 은 카톤당 세트 수로 나눠 카톤 수로 풉니다 (예: 120 set = 카톤 10). 해석 칸에 "= 10개 (1개 = 12 set)" 처럼 보입니다.
  - 단위: "세트" = 수주의 set, "낱개(pcs)" = 색연필 개수, "ea" = 그 품목 개수 그대로.
  - 세트가 없는 낱개 카톤 (색연필 ×1000) 에 set 을 넣으면 개수 그대로 계산하고 해석 칸에 알립니다 (색연필 수는 pcs 로). BOM 설정에서 직접 만든 구성은 예전처럼 개수 그대로입니다.
- **진행 중 수주에서 가져오기를 처음 · 중간 · 여러 번 눌러도 한 번만 셉니다**: 예전에는 누를 때마다 더해져 같은 수주가 두 번 · 세 번 들어갔습니다. 이제 같은 수주를 다시 가져오면 더하지 않고 지금 남은 set 으로 바꾸고, 끝난 수주 (완료 · 다 포장) 는 뺍니다. 이미 넣은 수주는 창에 "MRP 에 있음" 이 보입니다. 손으로 고친 수량은 그대로 남습니다.
  - 이 버전 전에 가져온 줄은 어느 수주인지 기록이 없어서, 같은 품번을 다시 가져오면 이번에 고른 수주의 남은 set 으로 새로 채웁니다 (알림이 나옵니다).
- **수주 화면의 MRP 단추** (품번 줄 · 자재 소요량 계산 (전체 품번)): 같은 품번이 여러 PO 에 있으면 큰 값 하나만 남던 것을 합치게 했습니다. 같은 PO 를 다시 눌러도 늘지 않습니다.
- 현장 재고 → 원재료 환산은 그대로입니다 (재고 수량을 품목 단위 그대로 풉니다).

## 1.13.5 — 자동 업데이트 받기 고침

1.13.4 에 이어, 자동 업데이트가 새 설치 파일을 받는 도중에 "남은 설치 파일 정리" 가 받던 파일을 지워 받기가 실패할 수 있던 것을 고쳤습니다. 화면과 쓰는 방법은 그대로입니다.

- ERP 를 켠 지 30초에 한 번 더 도는 정리가, 받는 중이면 기다렸다가 나중에 합니다 (예전에는 켜자마자 [업데이트 확인] 을 누르고 받기가 30초를 넘기면 받던 파일을 지워 "ENOENT" 오류가 났습니다. 보통의 첫 확인은 켠 지 1분 뒤라 거의 겹치지 않았습니다).
- 1.13.3 (보안 · 안정) · 1.13.4 (정리) 의 고침이 모두 들어 있습니다. 구글 Apps Script 는 7판 그대로입니다.

**받을 파일**
- `ColorPencil-ERP-Setup-1.13.5.exe` — Windows 설치 파일 (1.10.0 이상은 자동 업데이트)
- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모 (공유 기능은 설치형에서만)
- `latest.json` — 자동 업데이트가 보는 파일

## 1.15.5 — 배합표 원료 연결: 이름이 같은 원재료가 여러 코드면 소요량 계산이 볼 코드를 고름

- **소요량 계산 (MRP) 이 원료 연결을 먼저 봅니다.** 배합표의 원료 이름 (예: Carmine 6B) 과 이름이 같은 원재료가 여러 코드 (BC6B · R-029 · R-029P) 이면, 예전에는 품목 표에서 먼저 나온 코드 (BC6B) 의 재고로 셌습니다. 이제 생산 반영처럼 코드 연결 (원료 이름) 에 연결한 코드가 먼저입니다.
- **제품 · BOM · 배합 → 배합표 탭 위에 "원료 이름이 같은 원재료" 칸**이 생겼습니다. 이름마다 소요량 계산이 볼 코드를 고르세요 (코드 · 품명 · 재고가 보임). 고르지 않으면 예전처럼 품목 표에서 먼저 나온 코드입니다.
- 고른 것은 코드 연결 (원료 이름) 에 저장되어 모든 PC 에 같이 갑니다. 생산 반영 → 연결한 코드 목록에서 보고 지울 수 있습니다.
- 생산 계획 (사용자 구성 BOM) 의 숫자는 바뀌지 않습니다. 소요량 계산이 배합표를 쓰는 것은 사용자 구성 BOM 이 없는 품번입니다.

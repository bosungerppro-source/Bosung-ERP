## 12차 (v1.7.0) — 메뉴 3개: 품목 / 현장 재고 / 원부자재 재고

- **왼쪽 메뉴를 셋으로 나눴습니다**: 예전 "품목 · 재고" 한 메뉴 대신
  - **품목** — 품목 마스터 · 코드 사전 · 자료 점검 · 예시 자료
  - **현장 재고** — 현장 재고(심 → 배럴 → … → 조립 → 포장) · 생산 반영 · 수불 입력 · 수불 내역
  - **원부자재 재고** — 원부자재 재고(RM · SM · CM) · 수불 입력 · 수불 내역 · 발주 · 안전재고 · 외주 입출고
- **현장 재고와 원부자재는 따로 갑니다**: 수불 입력 · 수불 내역 · 왼쪽 메뉴의 경고 숫자도 메뉴마다 그쪽 품목만 다룹니다. 다른 쪽 품목을 넣으면 "원부자재 재고 메뉴에서 입력" / "현장 재고 메뉴에서 입력" 으로 알려 줍니다. 생산 반영은 지금처럼 원부자재를 차감하지 않습니다.
- **ECOUNT 비교를 없앴습니다**: ECOUNT 는 다음 달부터 쓰지 않으므로 비교 탭 · "비교만" 올리기를 지웠습니다. ECOUNT 재고현황 파일은 기초재고를 넣을 때만 씁니다.
- **확인되지 않은 이름은 코드만 보입니다**: 짐작해서 넣었던 이름과 물음표(?)를 지웠습니다. 예: WIP11 · WIP21·31… · WIP55 · WIP06·x6 · WIP15·25·35 · CM 은 코드로 보입니다. **품목 → 코드 사전**에서 이름을 넣으면 화면 전체에 바로 나오고, 지우면 다시 코드만 보입니다.
- **화면 정리**: 빈 표 · 빈 목록 아래에 "null" 글자가 보이던 것을 고쳤고, "이동?" 표시는 "이동 누락" 으로 바꿨습니다.

**설치 후**: 왼쪽 메뉴에 품목 · 현장 재고 · 원부자재 재고가 따로 보이는지 확인하세요. 자료(품목 · 재고 · 수불 · 설정)는 그대로입니다.

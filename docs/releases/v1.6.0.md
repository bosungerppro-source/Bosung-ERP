## 11차 (v1.6.0) — 공정 중(현장) 재고 · 원부자재 분리 · BOM 사용량

- **생산 반영은 현장 재고만 차감**: 조립 · 스탬핑 · 포장의 BOM 부품(반제품 · 완제품)만 줄어듭니다. 원재료 · 부자재 · CM 은 생산 반영으로 **절대 차감하지 않습니다** (사출 수지 kg, 배합표 원료, BOM 에 들어 있는 부자재 포함). 원부자재 재고는 창고 입고 · 출고 · 이동 수불로만 바뀝니다.
- **현장 재고 실사 (TỒN KHO) 올리기**: 공정 중 부품(심 · 배럴 · 노즈콘 · 홀더 · 스푼)과 조립 색연필의 현장 수량을 엑셀 업로드에 올리면 공정 중 재고의 기초가 됩니다. 기준일 = 파일 이름의 날짜(예: 20.10.2026). 원부자재 재고(ECOUNT)와 기준일 · 기초를 따로 관리하고, 서로 지우지 않습니다. 부자재 행 · TOTAL 행은 빼고 알려 줍니다.
- **배럴 계열**: WIP11 · WIP21 · … (WIPx1) 은 모두 배럴(WIP01). 조립 BOM 자동 구성의 배럴 후보 = WIP11 → WIP21 … → WIP01. 생산현장 흐름에 WIP11 · WIP21·31… 카드.
- **BOM 사용량 (배합표, 원료 g/개)**: `components` 시트를 그대로 올리면 인식합니다. 기본 "전체 교체" — 최신 판을 올리면 통째로 바뀝니다. 같은 코드가 두 번이면 첫 행을 쓰고 목록을 보여 주며, 향기오일 이름은 비고로 남깁니다. 재고 차감에는 쓰지 않고 소요량(MRP) · 신고서 계산에만 씁니다.

**설치 후**: 엑셀 업로드에 현장 재고 실사(TỒN KHO) · BOM 사용량 파일을 올리고, 품목 · 재고 → 생산현장 재고 탭에서 "현장 실사 기준일" 을 확인하세요.

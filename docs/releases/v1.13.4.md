## 1.13.4 — 정리 (코드 검토 나머지 3개)

화면과 쓰는 방법은 그대로입니다. 구글 Apps Script 는 7판 그대로입니다 (다시 배포할 것 없음).

- **저장 합치기를 한 코드로**: 화면 (여러 PC 가 같은 ERP 에 저장할 때) 과 구글 드라이브 공유가 같은 합치기 코드를 씁니다. 손으로 고친 파일 등에 같은 ID 의 행이 두 개 있으면, 화면에서도 서버처럼 나눠 따로 고칠 수 있습니다 (예전에는 화면에서 한 행으로 섞였습니다). 저장 답을 못 받아 양쪽에 같은 행이 생긴 경우는 "같은 행을 동시에 고침" 으로 세지 않습니다.
- **오류 글 한국어**: 사내망의 다른 PC 에서 할 수 없는 일 (PIN · 자동 백업 · 공유 연결 · AI 키) 과 PIN 형식 · Apps Script 주소 안내가 한국어 · 베트남어로 나옵니다 (예전에는 영어 · 베트남어).
- **저장이 가벼워짐**: 저장할 때마다 백업 폴더를 훑지 않고 (하루 한 번), 공유 상태를 볼 때마다 표 폴더를 읽지 않습니다.

**받을 파일**
- `ColorPencil-ERP-Setup-1.13.4.exe` — Windows 설치 파일 (1.10.0 이상은 자동 업데이트)
- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모 (공유 기능은 설치형에서만)
- `latest.json` — 자동 업데이트가 보는 파일

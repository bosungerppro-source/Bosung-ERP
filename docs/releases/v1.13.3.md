## 1.13.3 — 보안 · 안정 고침 (Apps Script 7판)

코드 검토에서 찾은 문제를 고쳤습니다. 화면과 쓰는 방법은 그대로입니다.

- **구글 비밀 키 보호**: 사내망의 다른 PC 브라우저 (PIN 으로 들어온 브라우저) 에는 구글 비밀 키를 보내지 않고, 그 브라우저에서는 웹 앱 주소 · 키를 바꿀 수 없습니다 (ERP 가 실행 중인 PC 에서만). 그 브라우저의 구글 시트 올리기 · 가져오기 · 휴대폰 요약은 ERP 가 키를 넣어 그대로 됩니다.
- **덮어쓰기**: "이 PC 자료로 구글 자료 덮어쓰기" 를 하면 이 PC 에 없는 표는 구글에서도 비웁니다 (예전에는 구글에 남아 있다가 오히려 이 PC 로 내려왔습니다). 이 ERP 가 모르는 표 (새 판 ERP 의 표) 는 건드리지 않습니다.
- **구글 시트 다시 쓰기**: [구글 시트 다시 쓰기] 를 누른 순간 인터넷이 끊겨도, 다시 되면 저절로 모든 탭을 다시 씁니다.
- **Apps Script 7판** (다시 배포해야 적용):
  - 휴대폰 보기는 비밀번호 대신 "이 휴대폰의 열쇠" 를 기억합니다. 누가 비밀번호를 10번 넘게 틀려 잠겨도 기억해 둔 휴대폰은 그대로 봅니다. 비밀번호를 바꾸면 기억해 둔 휴대폰도 다시 넣어야 합니다. 예전에 기억한 비밀번호는 다음에 열 때 열쇠로 바뀝니다.
  - 표 머리글이 아주 많아도 (구글 속성 한도 9KB) 저장이 실패하지 않습니다.
  - 같은 이름의 탭이 이미 있으면 "(ERP)" · "(ERP 2)" … 를 붙이고, 아주 긴 이름이어도 시트 갱신이 멈추지 않습니다.

**Apps Script 를 이미 배포했으면 (6판)**: [Apps Script 코드 복사] → Apps Script 편집기에 붙여넣기 → 저장 → 배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포 (주소는 그대로). 6판 그대로여도 자료 공유 · 시트 보기는 됩니다 (위 7판 고침만 없음).

## 15차 (v1.10.0) — 자동 업데이트 · 휴대폰으로 보기

- **자동 업데이트**: 1.10.0 부터 설치한 ERP 가 GitHub 에 새 버전이 있는지 스스로 확인합니다 (켤 때 · 4시간마다).
  - 새 버전이 있으면 설치 파일을 뒤에서 받아 두고, 파일이 온전한지 확인합니다.
  - 화면 위에 "새 버전 준비됨" 이 뜨고, **[지금 업데이트]** 를 누르거나 **다음에 ERP 를 켤 때** 설치됩니다 — 진행 막대가 잠깐 보이고 새 버전으로 켜집니다. 일하는 중에는 저절로 다시 시작하지 않습니다.
  - 설치 전에 데이터 폴더를 따로 복사해 둡니다 (최근 5번). 데이터 · 설정은 그대로입니다.
  - 설정 → 프로그램 업데이트 (또는 프로그램 메뉴 ERP → 업데이트 확인 · 자동 업데이트) 에서 끄거나 지금 확인할 수 있습니다.
  - **처음 한 번은 직접 설치**: 1.9.0 이하에는 이 기능이 없으므로 PC 마다 이 설치 파일을 한 번 덮어 설치하세요. 그 뒤부터는 저절로 바뀝니다.
- **휴대폰으로 보기**
  - **공장 Wi-Fi 안에서**: 사내망 접속을 켜고 PIN 을 정하면, 설정 → 휴대폰으로 보기의 QR 코드로 휴대폰에서 ERP 를 그대로 엽니다. 휴대폰 화면에 맞게 메뉴는 [☰] 로 접히고, 표는 칸 안에서 옆으로 넘깁니다. "홈 화면에 추가" 하면 앱처럼 열립니다.
  - **공장 밖에서**: 구글 웹 앱(`google/Code.gs` 4판)을 배포하고 설정 → 휴대폰으로 보기에서 비밀번호를 정하면, ERP 가 15분마다 종합 현황 · 생산 관리 요약을 보내고 휴대폰은 그 웹 앱 주소를 비밀번호로 엽니다 (데이터 요금으로도).

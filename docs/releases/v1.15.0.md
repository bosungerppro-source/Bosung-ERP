## 1.15.0 — 현장 재고를 공정마다 따로

현장 재고에서 공정을 여러 개 체크하면 서로 다른 공정의 재고가 한 칸에 더해져 "중복" 처럼 보이던 문제를 고쳤습니다. 이제 공정마다 따로 셉니다.

- **현장 재고 위 = 공정 카드**: 사출 · 리필 성형 · 조립 · 종이 권취 · 포장 (분류 안 된 품목이 있으면 카드 하나 더).
  - 공정끼리, 다른 구분끼리 (배럴 + 스푼), 다른 단위끼리 (세트 + 박스) 는 더하지 않습니다.
  - 사출 = 배럴 · 노즈콘 · 홀더 · 스푼 · 그 밖의 부품 × 품목군 (Mini · Dial · Pencil · Click pencil).
  - 리필 성형 · 종이 권취 = 품목군. 조립 = 품목군 × 조립품 · 조립 중간품. 포장 = 품목군 × 세트 (SET) · 박스 (CT).
  - 사출 일보의 묶음 이름 (Barrel · Holder …) 생산은 일보 줄의 품목군으로 나눠, 조립이 쓴 부품과 같은 칸에서 셉니다.
  - 칸에 마우스를 올리면 "실사 + 생산 − 사용 ± 기타 = 현재" 가 보입니다. 칸을 누르면 아래 품목 표가 그 품목으로 바뀝니다.
  - 카드마다 경고: 마이너스 · 못 넣은 일보 · BOM 없는 생산 · 단위를 못 바꿈.
  - [엑셀 (공정마다 시트)] — 공정마다 시트 하나 + 품목 목록.
- **공정 · 구분 · 품목군은 ERP CODE (이카운트) 를 쓰지 않고 ERP 가 정합니다.**
  - 생산 일보 · 색상별 BOM · 리필 규격 · 품목 구성 · 반제품 목록 · BOM 구조 · 품명으로 정합니다.
  - 품목 기준 정보의 '생산 공정' · '현장 구분' · '현장 품목군' 을 넣으면 그것이 먼저입니다.
- 아래 품목 표는 공정 탭 · 구분 · 품목군으로 고릅니다.
- 종합 현황의 '현장 재고' 위젯은 공정 하나를 고릅니다 (예전 '모든 공정' 위젯은 공정 카드 묶음으로 보입니다).
- 재고 숫자 계산은 그대로입니다 (묶어서 보이는 방법만 바뀜). 예전 표 설정은 지우지 않았습니다.
- 포장 재고에서 출고를 빼는 일은 다음에 정합니다.

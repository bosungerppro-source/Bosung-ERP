## 9차 (v1.4.0) — 여러 PC 동시 사용 · 보안 · 자동 백업 · AI 비서

- **여러 PC 동시 사용**: 같은 표를 동시에 고쳐도 행 단위로 합쳐 저장, 설정은 바뀐 항목만, 다른 PC 변경을 20초마다 불러옴, 저장 실패 시 자동 재시도
- **보안**: 다른 웹사이트가 보낸 요청 차단 (Host · Origin 검사), 사내망의 다른 PC 는 PIN 을 넣어야 접속
- **PC 밖 자동 백업**: USB · NAS · 구글 드라이브 동기화 폴더에 매일, 구글 드라이브에도 (Code.gs 3판)
- **AI 비서**: 재시작해도 AI 모드 유지, 대화 기록을 고치지 않아 API 오류 없음, 거절 · 잘림 처리, 서버 중계에 하루 호출 한도, 내장 모드가 잘못 알아듣던 질문 23개 고침

**설치 후**: 사내망을 쓰면 설정에서 PIN 정하기 · 자동 백업 폴더 지정 · 구글 드라이브 백업은 Code.gs 3판 다시 배포 · AI 모드는 ⚙ 에서 키 입력 후 AI 연결 시험

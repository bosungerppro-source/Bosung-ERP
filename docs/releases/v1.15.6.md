## 1.15.6 — 현장 재고는 마이너스 대신 0 으로 보임

- **현장 재고 (반제품 · 완제품) 의 재고 수량이 계산으로 0 아래가 되면 0 으로 보입니다.** 공정 카드 · 아래 품목 표 · 수불부 · 수불 입력 · 엑셀 · 통합 검색 · 수주 상세 · 품목 상세 · 해외 주문 · 자료 점검 · 종합 현황 위젯 · 휴대폰 · AI 비서 모두 같습니다.
- 그런 품목은 상태가 **"0 으로 보임"** 이고, 공정 카드 경고 **"0 으로 보임 N품목"** 을 누르면 아래 표에 그 품목만 나옵니다. 품목 목록은 **원부자재 재고 → 자료 점검 → "0 으로 보이는 현장 재고"** 에도 있습니다 (숫자 없이).
- **계산은 바뀌지 않습니다** (재고 · 생산 계획 · 소요량 계산 · 해외 주문 권장 주문량). 생산 · 소모 같은 수불 숫자 (± 칸) 도 그대로입니다.
- **원부자재는 예전처럼** 마이너스가 보입니다 (종합 현황 "마이너스 재고" = 원부자재만, 현장은 "0 으로 보임" 수가 따로).
- 현장 재고가 0 아래로 계산되는 까닭은 대개 생산 일보 · BOM 의 품목코드가 현장 실사 코드와 다른 것입니다 — BOM 을 일보 코드로 맞추면 줄어듭니다.

## 1.13.17 — 접속 중인 PC 이름 보기 (구글 드라이브 공유)

- **여러 PC 자료 공유에 "접속 중인 PC" 가 보입니다**: 설정 화면의 "여러 PC 자료 공유" 카드와 엑셀 · 구글 연동 → 구글 시트 · 드라이브의 공유 카드에 PC 이름 (Windows 컴퓨터 이름) 과 상태가 나옵니다 — 3분 안에 구글과 맞춘 PC 는 **접속 중**, 그 밖은 마지막으로 맞춘 때 (하루 안). 이 PC 에는 "(이 PC)" 가 붙습니다.
- ERP 를 켜 둔 PC 는 30초마다 구글과 맞출 때 PC 이름을 같이 보냅니다. 몇 분 전인지는 구글 시계로 재서 PC 시계가 틀려도 맞습니다.
- **구글 Apps Script 8판**이 필요합니다 (사장님 PC 에서 한 번): [Apps Script 코드 복사] → Apps Script 편집기에 붙여넣기 → 저장 → 배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포 (주소는 그대로). 7판 그대로여도 자료 공유 · 구글 시트 보기 · 휴대폰 보기는 그대로 되고, 그동안은 표마다 "자료를 보낸 PC" 와 8판 안내가 보입니다.
- 다른 PC 의 ERP 는 이 Release 로 자동 업데이트되면 이름을 보내기 시작합니다 (그 전까지는 목록에 나오지 않음).

**받을 파일**

- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모 (공유 기능은 설치형에서만)
- `latest.json` — 자동 업데이트가 보는 파일

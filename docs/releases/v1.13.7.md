## 1.13.7 — 생산 관리 일별 · 월별 조립 생산량: 가로 = 날짜, 세로 = 품목군

생산 관리의 **일별 조립 생산량** · **월별 조립 생산량** 표를 가로 = 날짜, 세로 = 품목군으로 바꿨습니다 (종합 현황의 일별 · 월별 조립 생산량 위젯과 같은 모양).

- 일별: 열 = 1일 ~ 마지막 입력일 (날짜 아래 요일, 일보가 없는 날은 회색). 행 = 품목군 (Click pencil · Dial · Mini · Pencil …), 둘째 칸 = 월 합계, 마지막 줄 = 일 합계.
- 월별: 열 = 1월 ~ 12월 (달 아래 입력 일수). 행 = 품목군, 둘째 칸 = 연 합계, 마지막 줄 = 월 합계.
- 품목군 이름 · 합계 칸은 옆으로 넘겨도 왼쪽에 그대로 보입니다. [엑셀] 도 화면과 같은 모양으로 나옵니다.
- 위의 고르기 "행: 품목군별 / 행: 공정별" (예전 "열: …") — 공정별이면 세로 = 공정입니다. 숫자 · 공정 · 품목군 고르기 · 위 숫자 카드 · 아래 표 · 막대는 그대로입니다.
- 구글 Apps Script 는 7판 그대로입니다.

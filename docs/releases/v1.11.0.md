## 1.11.0 — 해외 주문 품목 (자재구매 파일 · 리드타임)

- **자재구매 파일을 올리면** (엑셀 · 구글 연동 → 자료 올리기, `Category · Item Code · Safety stock …` 표):
  - 그 품목에 **해외 주문** 표시 · 구분 · 한글 품명 · 파일 순서, **안전재고 = 파일의 Safety stock** (단위가 ERP 와 다르면 해외 주문 표에서만 파일 단위로).
  - ERP 에 없는 품목은 파일의 이름 · 단위로 새로 만들고, 파일에 없는 품목은 해외 주문 목록에서 뺍니다.
  - 주문일 칸 · 입고예정 칸의 수량이 **주문**으로 들어갑니다 (다시 올리면 파일 값, 입고 완료로 둔 주문은 그대로).
- **원부자재 재고 → "해외 주문 품목만" 버튼 / 해외 주문 탭**: 파일과 같은 칸 순서의 표
  - 구분 · 품목코드 · 품명 · 품명(한글) · 안전재고 · 단위 · 재고 · 입고예정 · 주문일 칸 · 합계 · kg/월 · ea/월 · 최대 · 최소 · 평균
  - 뒤에 **리드타임(일) · 도착 예정 · 상태(주문 필요 / 충분) · 권장 주문량**
  - 재고 = ERP 원부자재 재고 (창고 입출고장 · 수불). 파일의 재고와 다르면 그 아래에 "파일 …" 로 같이 보입니다.
  - 주문일 칸에 수량을 넣으면 바로 저장, [+ 주문 칸] · [권장 주문량 넣기] · [입고 완료] · [엑셀 (같은 표)].
  - 리드타임은 기본값과 품목별로 넣습니다. 주문 필요 = 합계 − 리드타임 동안 쓸 양 < 안전재고.
- 발주 · 안전재고의 발주 필요 목록에서는 해외 주문 품목을 빼고 해외 주문 탭으로 안내합니다. 발주 필요 목록의 권장 발주량이 "–" 로 나오던 것도 고쳤습니다.
- 1.10.2 까지의 내용 (포장 카톤 재고 바로잡기 · 월별 조립 생산량 · 외주 반제품 창고 재고) 도 들어 있습니다.

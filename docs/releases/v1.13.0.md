## 1.13.0 — 여러 PC 자료 공유 (구글 드라이브)

- 사장님 PC 와 직원 PC 의 ERP 가 **구글 드라이브를 거쳐 같은 자료**를 씁니다.
  - 한 PC 에서 입력하면 보통 1분 안에 다른 PC 에 들어옵니다. 같은 사무실 · 같은 네트워크가 아니어도 되고, 사장님 PC 가 꺼져 있어도 됩니다.
  - 표를 통째로 덮어쓰지 않고 **행 단위로 합칩니다**. 같은 행을 두 PC 가 거의 동시에 고쳤으면 나중에 맞춘 PC 의 내용이 남습니다.
  - 종합 현황 배치 · AI 비서 · 붙여넣기 숫자 형식은 PC 마다 따로입니다.
- 설정: **엑셀 · 구글 연동 → 구글 시트 · 드라이브** 맨 위 "여러 PC 자료 공유" 카드.
  1. 사장님 PC: [Apps Script 코드 복사] → 새 구글 시트 → 확장 프로그램 → Apps Script → 붙여넣기 → 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자) → 액세스 승인 → 웹 앱 URL 을 붙여넣고 [연결 확인] → [이 PC 자료를 올리고 공유 시작].
  2. 직원 PC: 이 버전을 설치 → 사장님 PC 카드의 [직원 PC 연결 코드] 를 붙여넣고 [연결 확인] → [구글 자료로 시작].
- 왼쪽 아래 "☁ 구글 공유 · 시각" 으로 마지막으로 맞춘 시각이 보입니다. ERP 를 끌 때 아직 보내지 못한 입력이 있으면 보내고 닫습니다.
- 안전: 다른 PC 에서 많이 지워 이 PC 의 표가 절반 아래로 줄면 지우기 전 자료를 데이터 폴더의 `cloud_backup` 에 복사해 둡니다. 직원 PC 를 "구글 자료로" 시작할 때도 그 PC 의 자료를 먼저 복사합니다.
- **구글 Apps Script 5판** (`google/Code.gs`): 공유를 쓰려면 새 코드를 붙여넣고 배포하세요. 같은 웹 앱 주소로 **휴대폰 보기**(설정 → 휴대폰으로 보기 → 비밀번호)도 그대로 됩니다.
- 1.12.5 까지의 내용도 들어 있습니다.

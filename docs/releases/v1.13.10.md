## 1.13.10 — 포장한 만큼 조립 재고가 줄어듦

- **포장 일보 → 조립 재고 차감**: 포장 일보에는 박스 코드만 적힙니다. 이제 박스 BOM 의 세트(SG · 마니라)를 거쳐, 세트 안에 든 조립품(색 연필)을 포장 set 만큼 현장 재고에서 뺍니다 (예: 12색 박스 5,800 set → 12색 연필 각 5,800 자루). 세트 재고와 원부자재(마니라 · 카톤)는 빼지 않습니다.
  - 박스에 세트가 여러 가지면 BOM 수량 비율로 나눕니다.
  - 박스 수(CT당 set)를 몰라 박스로 입고하지 못하는 줄도 조립품은 뺍니다. 박스 입고는 지금처럼 CT당 set 이 있어야 합니다.
  - 현장 실사일까지의 포장은 실사 수량에 이미 들어 있어 세지 않습니다.
  - 일보에 세트 코드로 직접 적힌 생산이 있으면 그 세트는 예전처럼 뺍니다.
  - 현장 재고 → 생산 반영 탭: "박스 포장: 세트(SG) 대신 세트 안의 조립품을 뺌 (규칙)" — 세트마다 일보 줄 · 포장 set · 뺀 조립품 (pcs).
- 자료는 바뀌지 않습니다 (계산만 바뀜). 구글 Apps Script 는 7판 그대로입니다.

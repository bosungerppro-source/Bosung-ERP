## 1.13.1 — 여러 PC 자료 공유: 직원 PC 여러 대

- 직원 여러 명이 각자 ERP 를 설치해 입력 · 엑셀 업로드를 해도, 자료는 구글 드라이브 한 곳에 모여 모든 PC 에 업데이트됩니다 (PC 대수 제한 없음).
- 구글 Apps Script (5판) 가 "바뀐 것 있나" 물음에 캐시로 답합니다. PC 가 여러 대여도 구글 계정의 하루 한도를 쓰지 않습니다.
  - 아직 배포하지 않았으면 이 판의 [Apps Script 코드 복사] 로 붙여넣으세요.
  - 1.13.0 코드로 이미 배포했으면 새 코드를 붙여넣고 배포 → 배포 관리 → 수정 → 새 버전으로 배포하면 됩니다 (주소는 그대로).
- 1.13.0 의 내용 (구글 드라이브 공유 · 직원 PC 연결 코드 · 휴대폰 보기) 이 모두 들어 있습니다.

## 1.13.8 — 품목군 여러 개 골라 보기 (생산 관리 · 종합 현황)

현장 재고처럼, 보고 싶은 품목군을 여러 개 골라 그 품목군만 볼 수 있습니다.

- **생산 관리 → 일별 · 월별 조립 생산량**: 표 위의 "품목군" 체크 (전체 · Click pencil · CP Lead · CPCL · Dial · Mini · Pencil …) 에서 여러 개를 고르면 고른 품목군 줄만 나오고, 합계 · 위 숫자 카드 · 아래 표도 고른 것만 셉니다. 일별과 월별이 같이 쓰고, 고른 것은 저장됩니다 (공정마다 따로). "전체" 를 누르면 모두.
- **종합 현황 → 일별 · 월별 조립 생산량 위젯**: [✎ 화면 편집] → 위젯 ⚙ → 품목군에서 여러 개 체크 → [저장] (조립 재고 위젯과 같은 방식).
- 대소문자만 다른 품목군 이름 (Dial · dial, Pencil · pencil …) 은 고르기 목록에서 하나로 나오고, 고르면 둘 다 셉니다. 생산 관리 → 일보 조회의 품목군 고르기도 같습니다.
- 표 모양 (가로 = 날짜, 세로 = 품목군) · 숫자 · 제목은 그대로입니다. 휴대폰 보기는 그대로 모든 품목군입니다.
- 구글 Apps Script 는 7판 그대로입니다.

**받을 파일**
- `ColorPencil-ERP-Setup-1.13.8.exe` — Windows 설치 파일 (1.10.0 이상은 자동 업데이트)
- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모 (공유 기능은 설치형에서만)
- `latest.json` — 자동 업데이트가 보는 파일

## 1.15.1 — 빈 '분류 안 된 품목' 카드 숨김

- 현장 재고에서 재고가 0 인 분류 안 된 품목만 있으면 '분류 안 된 품목' 카드가 빈 채로 보이던 것을 고쳤습니다. 이제 보일 줄이 있을 때만 카드가 나옵니다.
- 그 카드의 [설정] 에서 "재고 0인 줄도 보기" 를 켜면 재고 0 인 품목도 보입니다.
- 나머지는 1.15.0 과 같습니다 (현장 재고 = 공정마다 따로 — 사출 · 리필 성형 · 조립 · 종이 권취 · 포장).

**받을 파일**
- `ColorPencil-ERP-Setup-1.15.1.exe` — Windows 설치 파일 (1.10.0 이상은 자동 업데이트)
- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모 (공유 기능은 설치형에서만)
- `latest.json` — 자동 업데이트가 보는 파일

## 14차 (v1.9.0) — 창고 입출고장 → 원부자재 재고

- **창고 입출고장(BẢNG KÊ NHẬP XUẤT) 올리기**: 엑셀 업로드에 그대로 올리면 원부자재 품목을 맞추거나 만들고, 1월 1일 기초재고(기말 재고 − 입고 + 출고)와 입고 · 출고를 넣어 마지막 날 재고가 파일의 재고(Tồn cuối kỳ)와 같아집니다.
  - 품목코드 = F, 세관신고 코드 = G, 품목명 = H (베트남어는 한국어로 바꾸고 원래 이름도 남김), 업체코드 · 업체 = D · E, 날짜 = C.
  - I 칸은 **용도**(생산 투입 · 외주 가공 · 반품 …) · **Lot** · **색깔** · 비고로 나눠 수불 내역에 보입니다.
  - 창고에서 나간 것은 원부자재 재고에서 빠지는 출고로 넣습니다.
  - 원재료 / 부자재는 출고 내용(원료 NL / 자재 vật tư)으로 나눕니다.
- **ECOUNT 재고현황으로 보완**: 같이 올리면 창고 입출고장이 기준이고, 같은 품목은 창고 수량, ECOUNT 에만 있는 품목만 더합니다. 마이너스는 0 으로.
- 창고 코드가 완제품 · 반제품 코드와 같으면 원부자재로 넣지 않고, 같은 물건일 수 있는 두 코드는 합치지 않고 알려 줍니다.
- 수불 내역 · 품목 상세에 업체코드 · 용도 · Lot · 색깔 · 세관신고 코드 · 베트남어 원래 이름이 보입니다.

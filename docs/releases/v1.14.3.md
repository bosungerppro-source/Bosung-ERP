## 1.14.3 — 수주가 겹쳐 들어가지 않게

11-06 에 생산관리 파일을 올리자 PO 미정 수주 16줄이 한 번 더 들어간 문제를 고쳤습니다 (겹친 줄은 그날 작업지시서 기준으로 정리했습니다).

- **생산관리 파일을 다시 올려도 PO 번호 없는 줄 (PO 미정) 이 겹치지 않습니다.**
  - 품번 · set · 납기로 같은 줄을 찾습니다. 구분2 · 마닐라 · 상태 같은 칸의 글자가 ERP 와 달라도 같은 줄입니다.
  - set 이나 납기만 바뀐 예측 줄도 같은 줄로 고칩니다.
- **이미 있는 수주와 같은 수주로 보이는 새 줄은 넣지 않고 알려 줍니다** (생산관리 파일 · 수주서).
  - 예: PO 번호의 숫자 순서가 바뀐 오타 (5100356187 = 5100365187), 품번을 앞부분만 읽은 줄 (68 = 68-7503-0-001).
  - 올리기 전 미리보기에 "같은 수주로 보여 뺌" 과 짝이 되는 줄이 보입니다. 정말 다른 수주이면 반영 방식에서 "비슷한 줄도 넣기" 를 고르세요.
  - 수주서와 생산관리 파일을 한 번에 같이 올려도, 먼저 반영될 파일의 줄까지 보고 미리보기를 보여 줍니다 (미리보기 = 반영 결과).
- **수주서를 더 맞게 읽습니다.**
  - `Item No : 68 7503 0 001` 처럼 띄어 쓴 품번 → 68-7503-0-001 (68-7503-0-001-A 같은 꼬리는 그대로).
  - "펜슬 24색+6색" → 30색 (pcs 도 30색으로).
- 생산관리 파일의 수주 묶음은 "갱신 · 추가" 만 고를 수 있습니다 (전체 교체 · 끝에 추가 없음).

**받을 파일**

- `ERP_Demo.html` — 설치 없이 브라우저로 여는 데모 (공유 기능은 설치형에서만)
- `latest.json` — 자동 업데이트가 보는 파일

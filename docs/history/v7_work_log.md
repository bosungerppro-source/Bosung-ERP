# 7차 — 위젯 종합 현황 · 원부자재/생산현장 재고 · 표로 답하는 비서 (2026-10-16, v1.2.0)

대상: 6차(v1.1.0) 소스. 요청 원문·해석·규칙은 `docs/PROMPT_v7_WIDGETS.md`, 개발 규칙은 `docs/CLAUDE_PROMPT.md` 2-6.

## 사용자 요청 (요약)
AI 비서 답변을 표 + 표 밑 코멘트로 · 수주 월별 수량을 품목군 기준으로, 품목군 다중 선택 · 종합 현황 위쪽 숫자를 사용자 지정 · 공정별 실적 설비 표시를 (가동/전체)로 · 일별 생산량 표는 월별 조립만 · 월별 수주량 = Checking 일 기준 pcs · 종합 현황을 스마트폰 위젯처럼 (기본 배치는 Claude가 정함) · 생산 수량은 재고로 입고, 조립 수량만큼 부품 차감 · 생산현장 재고와 원부자재 재고 탭 분리.

## 해석 (묻지 않고 정함)
- Checking 일 = PO `due` 열 (원본 열 이름 "Checking", 사용자 엑셀 PO Sum 과 같은 합계).
- 일별 생산량 표 = 종합 현황 위젯 + 생산 관리 탭, 한 달 · 품목군별 · 조립 기본.
- 원부자재 = RM·SM·CM, 생산현장 = WIP00 … FG.
- 위젯 배치 · 품목군 선택은 서버 설정(meta)에 저장 → 같은 ERP 에 접속하는 모든 PC 공용.

## 한 일
- 종합 현황 위젯 26종, 기본 배치 12개. 편집: 끌어 놓기 · ◀ ▶ · 크기 1~4 · ⚙ 설정 · ✕ 빼기 · 갤러리 · 기본 배치로.
- 수주 관리: 월별 × 품목군 표 (Checking/수주일 기준, 3/6/12개월, 행을 펼치면 품번, 엑셀 내보내기) + 품목군 칩.
- 품목·재고: 원부자재 재고 / 생산현장 재고 / 생산 반영 탭. 생산현장 표에 기초 · 생산 입고 + · 소모 − · 기타 ± 열.
- 생산 반영: `code_map` 표 (일보 코드·원료 이름 → ECOUNT 품목코드), 사출 원료 kg 차감, 해결할 항목을 화면에서 바로 고침.
- 제품·BOM: 조립 BOM 자동 구성 (ECOUNT 코드 기준). 직접 만든 BOM 은 보호하고, 자동으로 만든 줄은 `src:'auto'`.
- 생산 관리 일별 생산수량: 기본 = 품목군별 · 조립. 품목군 이름의 대소문자 차이는 한 묶음.
- AI 비서
  - 내장 모드: 블록 답변 (표 + ※ 코멘트, 복사 버튼).
  - AI 모드: Markdown 표 + ※ 코멘트 규칙과 그 렌더링. 넓게 보기 버튼.
- 버전 1.2.0. 시험은 `npm run test:v7` (6차 시험 포함, `selftest_v6.js` 삭제).

## 함께 고친 것 (이전 버전부터 있던 문제)
- 빠르게 연속 수정한 뒤 "저장 중…" 표시가 사라지지 않던 오류 (`DB.queueSave` 대기 수).
- 수정 후 0.7초 안에 창을 닫으면 마지막 수정이 저장되지 않던 문제.
  - 고친 방법: `DB.flush()` 추가, Electron 은 창을 닫기 전에 저장을 기다림, 브라우저 접속은 나가기 확인 창.
  - 실제 Electron 으로 확인: 1.1.0 은 수정이 사라지고, 1.2.0 은 저장됨.
- 베트남어 화면에 `건` · `개` · `1월` 이 한국어로 나오던 문제 (`L(ko, '')` 규칙).
- `npm test` 가 Node 에서 바로 멈추던 오류.
- 일별 조립 표에서 고정 열 두 개가 가로 스크롤 때 겹칠 수 있던 폭 문제.

# 나만의 AI 비서 — 작업 기록 (2026-10-15)

대상 프로그램: ColorPencil ERP (JavaScript/Electron, `erp-source_1.zip`). 요청: "AI 생산 비서를 프로그램 안에 넣어 나만의 비서로".
※ 처음 첨부된 progress 보고서는 다른 프로그램(Python "ERP AI": Kakao·Ollama·phrasebook)의 것이었음. 이번 작업은 JS ERP 안에 비서를 만든 것이며 그 기능(Kakao 알림, Ollama, 자동번역 phrasebook)은 포함하지 않음.

## 이번에 한 일
- `app/js/assistant_tools.js` (신규): 읽기 전용 도구 9개. AI 모드·내장 모드가 같은 함수를 써서 숫자가 대시보드와 일치 (기존 비서는 납기 경과 193 vs 대시보드 31로 달랐음).
- `app/js/assistant_local.js` (신규): 내장 모드 — API 키·인터넷 없이 한국어/베트남어(성조 유무)/영어 키워드 질문에 답하고 화면 이동 버튼 제공. AI 가 아니라 정해진 질문 유형만 이해.
- `app/js/assistant.js` (재작성): 나만의 설정(이름·호칭·스타일·공장 지침·단축 질문 8개·AI 끄기), 오늘 브리핑, AI 모드(도구 호출 루프 8회 제한, 오류 시 기록 복구, 실패하면 내장 모드로 자동 전환).
- `server.js`: 키 변경은 ERP 가 실행 중인 PC(loopback)에서만, 화면엔 끝 4자리만, 프록시 시간 초과/네트워크 오류 구분.
- `app/js/db.js`: "전체 삭제" 후 재시작하면 샘플 데이터가 다시 들어오던 버그 수정 (seeded 표시·ai* 설정 유지).
- `app/js/main.js`: 데이터 로드 직후 비서 버튼 이름을 갱신 (재시작 직후 사용자 지정 이름이 안 보이던 문제).
- 문서: README, docs/CLAUDE_PROMPT.md (5차 개정), `npm run test:assistant`.

## 숫자 기준
- 납기 경과 = 납기 후 60일 이내(대시보드). 60일 초과 = "오래된 지연"(stale) 별도. 수주 화면 "납기 경과" 탭(193) = 31 + 162. 메뉴 배지는 30일, 수주 KPI 는 90일 기준이라 화면마다 창이 다름.
- 안전재고는 설정한 66/980종만 판단. MRP 는 BOM 부품·배합이 없으면 "계산 불가".

## 검증 상태
- 자동 시험 233개 통과 (Playwright/Chromium): 대시보드 숫자 일치, 질문 분류 103개(한국어·베트남어 성조 유무·영어, 실제 PO/품번/자재/고객 포함) + 답변 형식 검사 244회, 화면 동작, 설정 저장/백업/전체 삭제, AI 모드(가짜 API), 서버 프록시·키 보호, 모든 화면, 단일 파일 데모. 코드를 일부러 망가뜨려 시험이 실패하는 것도 확인.
- 설치 파일(ColorPencil-ERP-Setup-1.0.0.exe): Linux 에서 빌드, 포함된 앱 코드가 시험한 소스와 동일함을 확인. **Windows 에서 설치·실행은 시험하지 못함.**
- **실제 Anthropic API 로는 시험하지 못함** (가짜 응답으로만).

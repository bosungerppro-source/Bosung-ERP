# 16차 작업 기록 — 해외 주문 품목 (자재구매 파일 · 리드타임) (v1.11.0, 2026-10-21)

요청 · 규칙: `docs/PROMPT_v16_BUY.md`.

## 요청
- "안전재고 참고해주고 여기에있는 품목만 원부자재 탬안에 따로볼수있게 버튼을 만들어주고 이품목만 따로 주문할수있게 안에 표 형태를 유지해줘. 이품목은 해외에서 주문하는거기때문에 리드타임이있어서 따로 관리해야한다." (첨부 `261021 자재구매.xlsx`)

## 파일 살펴본 것
- `Oder Korea` 시트: 4행 머리 (Category … Inventory · 입고예정 · 2026-10-21 · 2026-09-21 · Total · kg/month · ea/month · Max · Min · Average), 5행 엑셀 표 머리, 6~86행. 주문일 머리 칸은 엑셀 날짜 숫자 (46316 = 2026-10-21 — `cellDates` 로 읽으면 이 PC 시간대에서 10-20 23:59:56 이 되므로 숫자 그대로 `F.parseDate`).
- Total = Inventory + 입고예정 + 주문일 칸 → **입고예정 칸은 주문일 칸과 따로** (처음에는 "입고예정 = 입고 대기 주문 합"으로 만들었다가, 그러면 합계 · 내보낸 표 · 다시 올리기에서 두 번 세어져 고침 — `kind: 'inc'`).
- kg/month · ea/month: 옆 표(S:W)의 출고 피벗 (kg 와 개 = 포대 · 통 수, 예: 140 kg = 14 ea), 개 품목(Hot foil)은 kg/month 가 비어 있음 → ERP 도 개 품목의 kg/월 은 비움.
- 다른 시트 (Sheet1 월별 사용량, Sheet2 지난해 출고 장부, Sheet3 · Sheet4 메모, Oil Order) 는 인식하지 않음 (인식 불가로 건너뜀).

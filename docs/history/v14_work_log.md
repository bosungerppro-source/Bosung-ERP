## 요청

## 물어서 정한 것
- 재고 계산 = 1~10월 입출고까지 반영 (1월 1일 기초재고 = 기말 − 입고 + 출고, 마이너스면 0 + 조정).
- 품목 구분 = 출고 내용 (원료 NL → 원재료 · kg, 자재 vật tư → 부자재 · 개).

## 자료 분석에서 정한 것 (묻지 않음)
- 기말 재고(P/Q)는 줄마다 같은 값 (품목별 현재 재고) — 누적 잔액이 아님.
- 창고에서 나간 것 = 원부자재 재고에서 빠지는 출고 (11차: 생산 반영이 원부자재를 차감하지 않으므로, '창고 → 공장 이동' 으로 두면 재고가 줄지 않아 파일의 재고와 안 맞음).
- 창고 코드 22개가 ECOUNT 의 완제품 · 반제품 코드와 같음: 제품번호로 적은 카톤은 세관 코드 + 앞자리로 ECOUNT 카톤에 맞추고, 나머지(클릭펜 부품 · 홀더 · 리필 컨테이너 · 클릭펜슬 등 반제품)는 원부자재에서 뺌.
- 처음엔 'R-204VN → R-204' 처럼 VN 을 뗀 코드와 합쳤으나, 복사본 시험에서 두 창고 코드의 재고가 한 품목에 더해져 8개 품목이 기말 재고와 안 맞음 → 합치지 않도록 바꿈 (같은 물건일 수 있는 쌍은 알림).
- ECOUNT 재고현황의 반제품(WIP) 50개는 현장 실사(TỒN KHO) 기준이라 수량을 넣지 않음 (11차 규칙).

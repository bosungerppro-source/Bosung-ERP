## PROMPT

너는 BOSUNG VINA(베트남 색연필 공장) ERP를 유지보수하는 시니어 개발자다. 사용자는 대부분을 네가 판단해 적용하길 원하고, 정말 필요한 것만 묻는다. 기존 기능(수주·생산일보·BOM/MRP·ECOUNT 기준 재고·나만의 AI 비서·구글 연동·설치 파일)은 그대로 두고, 아래 변경을 **최신 소스(6차) 위에** 반영한다.

### 1. 사용자 요청 (원문, 2026-10-16)
> AI비서 보기가좀 불편해 표로 깔끔하게 볼수있게 해주고 표밑에 코멘트를 쓰도록 한다.
> 수주관리의 월별.아이템별 수주수량은 품목군으로하고 볼수있는 품목군은 중복선택가능하게해서 보고싶은거만 볼수있게 한다.
> 종합 현황 - 위쪽 기준일 포장 실적/이번달 /포장누계/ 납기 임박등 고정된게아니라 커스텀마이징해서 표시할수있게 해줘.
> 공정별 실적에 설비(전체/가동)을 설비(가동/전체)로 표시해줘
> 일별 생산량 표는 월별 조립만 표시한다.
> 월별 수주량은 checking 일 기준 pcs 수량으로 한다.
> 그리고 종합 현황을 스마트폰의 위젯처럼 커스텀마이징 할수있게 해줘 기본설정은 너가해주고
> 여기에 생산 수량이 재고로 들어가고 조립수량에 따른 부품수량차람이 가능하게 되야하고 생산현장재고 수량과 원부자재 재고를 따로 분리해서 탭을 나눠줘야한다.

### 2. 확정한 해석 (묻지 않고 정한 것)
1. **"Checking 일" = PO 의 납기(`due`) 열**이다. 원본 엑셀의 열 이름이 "Checking" 이고, 사용자 엑셀 "PO Sum" 의 월별 합계와 같은 값이 나온다. 수주일 기준도 고를 수 있게 남긴다(기본은 Checking).
2. **"일별 생산량 표"** = 종합 현황의 위젯과 생산 관리 "일별 생산수량" 탭 둘 다. 둘 다 **한 달 · 품목군별 · 조립(ASM)** 이 기본이다 (사용자 엑셀 "Assembly Sum" 과 같은 모양). 다른 공정은 위젯 설정·드롭다운에서 고를 수 있다.
3. **생산현장 재고** = 반제품·제품 단계 WIP00(심) … FG(박스). **원부자재** = RM(원재료) · SM(부재료) · CM(소모품). 코드 없는 품목(ETC)은 ECOUNT 품목구분이 원재료·부재료·원자재·소모품이면 원부자재, 나머지는 생산현장.
4. 위젯 배치는 이 ERP(서버)에 저장한다 → 같은 서버에 접속하는 모든 PC가 같은 배치를 본다 (공장 공용 현황판). 기본 배치는 아래 4-1.
5. 품목군 선택(보고 싶은 것만)은 **한 번 고르면 종합 현황 · 수주 관리 모두 같은 선택**을 쓴다.

### 3. 화면별 변경
#### 3-1. AI 비서 — 표 + 표 밑 코멘트
- 내장 모드(키 없음): 답변을 **블록**으로 만든다 — 제목 · 구역 · 표(+ 표 밑 `※` 코멘트) · 메모 · 목록. 화면은 진짜 표로 그리고, 같은 내용의 글자 버전(`text`)은 복사·메신저용으로 둔다 (`⧉ 복사` 버튼).
- AI 모드: 시스템 프롬프트 FORMAT 규칙 — 굵은 제목 1줄, 항목·숫자가 2개를 넘으면 Markdown 표(최대 12행), **모든 표 바로 밑에 `※` 로 시작하는 1~2줄 코멘트**(가장 큰 위험·차이·다음 확인), 긴 문단 금지. 화면은 안전한 Markdown 일부(표 · 굵게 · 목록 · `※` 코멘트)만 그린다 (HTML 은 글자로).
- 창 폭 600px, 위쪽 `⤢`(넓게 보기) 버튼 = 980px (브라우저별 기억).

#### 3-2. 수주 관리 — 월별 · 품목군별 수주량 (pcs)
- 행 = 품목군(PO `kind`), 열 = 월, 끝 = 합계. 행을 누르면 그 품목군의 품번별 수량이 펼쳐진다.
- 위쪽: 기준(Checking(납기) / 수주일) · 시작 월 · 3/6/12개월 · 엑셀.
- **품목군 칩(다중 선택)**: `✓ 전체` + 품목군별 칩. 끈 품목군은 표·합계에서 빠지고, 합계 행은 "보고 있는 품목군 합계".

#### 3-3. 종합 현황 — 스마트폰 위젯처럼
- `✎ 화면 편집` → 편집 모드: 위젯마다 막대 `⠿ (끌기) ◀ ▶ 1 2 3 4 (가로 칸) ⚙ (설정) ✕ (빼기)`, 맨 끝 `+ 위젯 추가` 타일, 위쪽 `기본 배치로` · `편집 완료`. 편집 중에는 위젯이 살짝 흔들린다(움직임 줄이기 설정이면 안 흔들림).
- 4칸 격자(좁은 화면 2칸, 휴대폰 1칸), 빈 칸은 뒤의 작은 위젯이 채운다(`grid-auto-flow: dense`). 위젯을 누르면 해당 화면으로 이동.
- 위젯 26종 (갤러리 5묶음):
  - 숫자(작게): 기준일 포장 실적 · 이번 달 포장 누계 · 납기 임박/경과 PO · 안전재고 미달 자재 · **공정 실적(기준일, 공정 선택, 여러 개)** · 공정 이번 달 누계(여러 개) · 진행 중 PO · 이번 달 수주량(Checking) · 이번 달 신규 수주 · 불량률 · 가동 설비(가동/전체) · 마이너스 재고 · 이동 누락 의심 · 생산 반영(재고)
  - 생산: 공정별 실적 · **일별 조립 생산량(월, 표/차트, 공정 선택, 여러 개)** · 공정별 생산 추이(30일) · 일보 입력 현황(7일)
  - 수주: **월별 수주량(Checking 기준, pcs, 품목군 칩, 차트/표)** · 납기 임박 수주
  - 재고: 안전재고 미달 자재 · 재고·공정 흐름 · 생산현장 재고 반영(7일)
  - 기타: 자료 최신 여부 · 바로가기 · 메모(여러 개)
- **공정별 실적** 카드의 설비 표시는 `설비 (가동 / 전체)` = `4 대 / 22 대`.

#### 3-4. 품목·재고 — 원부자재 / 생산현장 탭 분리
- 탭: **원부자재 재고** · **생산현장 재고** · **생산 반영** · 수불 입력 · 수불 내역 · 발주 · 안전재고 · 외주 입출고 · ECOUNT 비교 · 자료 점검 · 코드 사전 · 마스터 · 예시 자료. (예전 `stock` 탭 주소는 품목 단계에 맞는 탭으로 자동 이동)
- 원부자재 탭: 흐름 카드 3칸(원재료 · 부재료 · 소모품). 생산현장 탭: 흐름 카드 12칸(심 → 배럴 → 노즈콘 → 홀더 → 스푼 → … → 조립 → 마니라 → 박스 포장), 부품 · 스탬핑 · 조립 · 포장 묶음 이름.
- 생산현장 표 열: 코드 · 품명(+단계·제품군·고객 칩) · 단위 · **기초 · 생산 입고 + · 소모 − · 기타 ±** · 창고 · 공장 · 합계 · set · 상태 · 최근. 합계 = 기초 + 생산 입고 − 소모 ± 기타.
- KPI: 재고 있는 품목 · 생산 입고(기초 이후) · 생산 소모 · 마이너스.

#### 3-5. 생산 반영 탭 (생산 수량 → 재고, 조립 수량 → 부품 차감)
- 방식: `생산량 입고 + BOM 자재 차감`(기본) / `생산량만 입고` / `반영 안 함`. 기초재고 기준일 **다음 날부터**의 일보만 반영, 저장하지 않고 매번 계산(같은 일보를 다시 올려도 중복 없음).
- KPI: 반영 대상 일보 · 생산 입고 · 부품·원료 차감(BOM 출처별 건수) · 해결할 항목.
- 해결할 항목(펼침 목록, 바로 고치기):
  1. **품목코드가 아닌 일보 코드 → 품목 연결** (`code_map`). 제안 버튼(초록 = 확실) 또는 ECOUNT 품목코드 입력, `품목군별` 연결도 가능.
  2. **BOM 없는 생산품** (입고만 되고 부품 차감 안 됨) → `조립 BOM 자동 구성` · BOM 편집.
  3. 예시 BOM 의 부품코드가 ECOUNT 에 없음 (옛 코드 NM01064 · H001 …).
  4. 원료 이름 → RM 코드 연결 (사출 원료 kg 차감용).
  5. CT · SET 환산 없음 (포장 입고 불가).
  6. 연결한 코드 목록 (지우기).
- 최근 생산 반영(입고 · 차감) 표 → 수불 내역에서 보기.

#### 3-6. 제품·BOM — 조립 BOM 자동 구성 (ECOUNT 코드)
- 대상: 조립품(WIP · WIP55)과 스탬핑 배럴(WIP11). 부품 역할: 심(WIP00) · 배럴(WIP11 → WIP01) · 노즈콘(WIP02) · 홀더(WIP03) · 스푼(WIP04). 스탬핑 배럴은 스탬핑 전 배럴(WIP01).
- 찾는 규칙: ① 같은 제품군 + 같은 색 이름 + 코드 숫자 끝자리 일치(`digitScore`) ② 제품군에 하나뿐인 부품(MINI HOLDER · MINI SPOON 등)은 공용 ③ 제품군 이름이 붙은 부품. 예시 색상 BOM 에 "이 부품 없음"이면 그 역할은 건너뛴다.
- 결과 표: 부품마다 드롭다운(초록 = 확실, 노랑 = 골라야 함, 빨강 = 못 찾음), 상태 칩 `바로 적용 가능` / `일부 확인 필요` / `부품 못 찾음`, `확실한 부품만 모두 적용 (N)` 버튼, 행별 적용.
- 적용하면 `bom_lines` 에 `src:'auto'`, 소요량 1(부품 1개 / 펜 1자루, 다르면 BOM 편집에서 수정). **직접 만든 BOM(`src` 없음)은 덮어쓰지 않는다**. 자동 BOM 은 다시 적용하면 새 제안으로 바뀐다.

### 4. 데이터 · 계산 규칙
#### 4-1. 설정 (`ERP.db.meta`, 백업 포함)
- `dash`: `[{k, id, w, o?}]` (k = 위젯 고유 키, id = 위젯 종류, w = 가로 1~4칸, o = 위젯 설정 예: `{proc:'ASM', view:'table'}`). 없으면 기본 배치:
  `기준일 포장 실적(1) · 이번 달 포장 누계(1) · 납기 임박/경과 PO(1) · 안전재고 미달(1) · 공정별 실적(4) · 일별 조립 생산량(4) · 월별 수주량(2) · 납기 임박 수주(2) · 안전재고 미달 자재(2) · 재고·공정 흐름(2) · 자료 최신 여부(2) · 일보 입력 현황(2)`.
- `poKindsOff`: 숨긴 품목군 목록 (새 품목군은 자동으로 보임).
- 위젯 안의 달 이동 · 연도 이동은 화면 상태(`ERP.state['w_' + k]`)라 저장하지 않는다.

#### 4-2. 표
- `code_map` (7차 새 표): `kind`(daily | raw) · `proc` · `div` · `src`(일보 코드/이름 또는 원료 이름) · `item`(ECOUNT 품목코드) · `note`. 키 = kind+proc+div+src. 찾는 순서 (공정+품목군+코드) → (공정+코드) → (품목군+코드) → (코드).
- `bom_lines.src`: `auto` = 조립 BOM 자동 구성, 비어 있으면 직접 입력.

#### 4-3. 계산
- 월별 수주량 = `C.monthlyPO('due')` — PO 행의 `due` 가 속한 달의 pcs 합 (`pcs` 가 없으면 set × set당 pcs). 품목군 = `kind` 앞뒤 공백 제거, 비면 "미지정".
- 일별 조립(위젯·생산 탭) = 그 달의 ASM 양품 수량(pcs), 품목군은 대소문자·공백 차이를 한 묶음으로, 비어 있으면 "(품목군 없음)".
- 생산 입고: 일보의 품목코드(또는 `code_map` 연결)가 ECOUNT 품목이면 공장(FAC) +. CT 는 `set_per_ct`, SET 은 set, kg 는 무게.
- 부품 차감: BOM 순서 `bom_lines`(직접 → 자동) → 예시 색상 BOM → 배합표(리필 g/개 → kg) → 세트 구성. **사출(INJ)** 은 일보의 원료 `raw_kg` 를 원료 이름 → RM 코드(`code_map` raw, 없으면 옛 자재 이름 매칭)로 차감.
- 원부자재 / 생산현장 구분 = `INV.groupOf(item)` (3-4 규칙). `INV.MAT_STAGES`, `INV.FLOOR_STAGES`.

### 5. 지켜야 할 것
- 모든 문자열 `L(ko, vi)`. **`L(ko, '')` 는 베트남어에서 빈 글자**(예: `n + L('건', '')`), `L(ko)` / `L(ko, undefined)` 는 한국어로 대신 보인다. 월 이름은 `L(m + '월', 'T' + m)`.
- 데이터에서 온 이름(품목 · 코드 사전)은 `INV.label` 로 보이고 자체 대체 규칙을 쓴다(빈 베트남어 → 한국어).
- 자동 BOM 은 제안일 뿐: 직접 만든 BOM 을 덮어쓰지 않고, 확실하지 않은 부품은 자동 적용하지 않는다.
- 위젯 하나가 오류를 내도 나머지는 그린다(위젯 단위 try/catch).
- 계산 캐시 `DB.memo` 의 의존 표에 새 표를 넣는다(`code_map` 은 생산 반영 · 제안에 들어 있음).

## 8. 7차 구현 결과 (2026-10-16, v1.2.0)

### 실무자 사용 순서
1. 종합 현황 `✎ 화면 편집` → 필요 없는 위젯 ✕, `+ 위젯 추가` 로 원하는 숫자·표 추가, 끌어서(또는 ◀ ▶) 순서, 1~4 로 크기 → `편집 완료`.
2. 제품·BOM → `조립 BOM 자동 구성` → `확실한 부품만 모두 적용` → 노랑 행은 드롭다운으로 골라 적용.
3. 품목·재고 → `생산 반영` 탭에서 해결할 항목 0 으로 만들기(코드 연결 · BOM 없는 생산품).
